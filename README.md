**Автор:** Наздратенко И. Д., ПИб-23Э1

## Назначение

Одностраничный веб-сервис на FastAPI использует дообученную YOLO26n из лабораторной № 2 в формате ONNX. Пользователь выбирает фото, сервис выполняет реальный инференс, а браузер показывает ограничивающие рамки и confidence.

## Возможности

- Минималистичный адаптивный одностраничный UI Nazdratenko.
- Загрузка, перетаскивание и вставка изображения из буфера обмена.
- Отображение реальных этапов загрузки и прогрева модели.
- Детекция и рисование рамок на Canvas.
- JSON-логи с request_id, latency_ms и model_version.
- Docker Compose и Render Blueprint для одного сервиса на плане Free.

## Архитектура

Браузер → FastAPI → проверка и декодирование изображения → ONNX Runtime CPU → YOLO26n → JSON детекций → Canvas в браузере. При старте модель загружается и выполняет пробный инференс. /health проверяет жизнеспособность HTTP-приложения, а /ready становится успешным только после прогрева модели.

## Запуск одной командой

Из корня репозитория:

    docker compose up --build

Откройте http://localhost:8000. На бесплатном Render возможен холодный старт после периода простоя. Сайт покажет загрузку и прогрев, когда backend начнёт отвечать.

## API

    curl http://localhost:8000/health
    curl http://localhost:8000/ready
    curl http://localhost:8000/info
    curl -X POST http://localhost:8000/detect -F "file=@static/img/demo.jpg"

В PowerShell используйте curl.exe. POST /detect принимает multipart/form-data с полем file.

## Лимиты

- Поддерживаемые MIME-типы: JPEG, PNG, WebP.
- Максимальный размер файла: 4 MB.
- Максимальная сторона перед инференсом: 1280 px.
- Production runtime: ONNX Runtime CPU, ограничение потоков до одного.
- Изображения обрабатываются в памяти и приложением не сохраняются.

Время прогрева и inference_ms зависят от окружения. Их следует измерять по JSON-логам; фиксированное время не гарантируется.

## Тесты

Установите dev-зависимости и запустите:

    pip install -r requirements-dev.txt
    pytest -q

Для настоящего end-to-end smoke-теста работающего сервиса:

    bash scripts/smoke_test.sh

Скрипт ждёт /ready, проверяет /info и выполняет настоящую детекцию на static/img/demo.jpg. Для удалённого сервиса задайте BASE_URL.

## Render

Откройте https://dashboard.render.com/ → New + → Blueprint → выберите репозиторий. Файл render.yaml описывает один Docker Web Service с plan free. После выкладки проверьте /health, дождитесь /ready и выполните детекцию. Render Free может засыпать после простоя; файловая система не является постоянным хранилищем.

## Документация и эксплуатация

- MODEL_CARD.md — назначение, оценка и ограничения модели.
- RUNBOOK.md — запуск, readiness, ошибки, задержки, drift, request_id и rollback.
- ARCHITECTURE.md — схема компонентов.
- DEPLOY.md — локальный запуск и деплой на Render.

## Ограничения

Сервис предназначен для учебной демонстрации. Детекция может ошибаться и не подходит для решений, связанных с безопасностью инструмента или оборудования.
