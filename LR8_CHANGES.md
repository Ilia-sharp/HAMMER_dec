# Что добавлено для лабораторной работы № 8

## Интерфейс

- Одностраничный UI Nazdratenko: светлый минимализм, янтарный акцент, мягкие границы и адаптивная сетка.
- Загрузка файла, drag-and-drop, вставка из буфера обмена и демонстрационный кадр.
- Canvas с рамками модели, список детекций, уверенность и длительность инференса.
- Состояния подключения, загрузки модели, прогрева, готовности и ошибки.
- Процент передачи файла берётся из реального upload progress; процент прогрева не выдумывается.

## API и модель

- GET /health — liveness процесса.
- GET /ready — 503 до успешного прогрева и 200 после него.
- GET /info — безопасная информация о сервисе и ограничениях.
- POST /detect — реальный инференс обученной ONNX-модели.
- Модель загружается в фоновом потоке и выполняет пробный инференс.
- Один поток CPU и сериализация инференса подходят для лимита 0.1 CPU.

## Логи и ограничения

- JSON-логи включают request_id, latency_ms, model_version, маршрут, HTTP-статус и данные о времени инференса.
- request_id возвращается клиенту через X-Request-ID и JSON для успешного и ошибочного инференса.
- Содержимое изображения и сырые пользовательские данные не логируются.
- Файл ограничен 4 MB, сторона изображения — 1280 px.

## Docker и Render

- Добавлены Dockerfile, compose.yaml, .dockerignore и закреплённые runtime requirements.
- Compose запускается командой docker compose up --build, порт 8000.
- Render Blueprint создаёт один Docker Web Service с планом free.
- Приложение читает PORT из окружения.
